# Cosmic Aquaria visual fidelity pass

## Scope

This pass changes only the presentation layer of the canonical two-screen listener application. Catalogue selection, randomisation, Bandcamp playback, deep links, sharing, navigation, analytics and the 1.5-second GO hold are unchanged.

## Material system

The shared controls now use a layered liquid-emerald material made from asymmetric radial illumination, conic refractive rims, nested inner ridges, deep rear-surface shadows, corner glints and sparse micro-bubbles. Category-specific custom properties vary the light origin, glint position, body colour and depth while keeping one manufactured visual language.

Selected controls retain their deterministic per-category fracture geometry and add a depressed dark cavity, shifted reflection, impact bloom, secondary shard planes and deeper edge collapse. The GO control uses the same construction in champagne/amber glass so it remains a distinct commitment control.

The player uses the same optical system for its outer chassis, recessed ticker, now-playing chamber, progress bead, three action controls and Bandcamp footer. The official Bandcamp embed is colour-integrated without obscuring or replacing its legal playback controls.

## Truthful visualiser limitation

The official Bandcamp iframe is cross-origin and does not expose its audio stream to the page's Web Audio analyser. The spectrum remains an explicitly labelled decorative release-seeded display; it is not represented as live audio analysis. The official player remains the source of truth for playback and timing.

## Responsive QA

Automated browser captures cover 390×844, 393×852 and 430×932. The application remains scroll-free and preserves the canonical 750:1280 machine ratio within each viewport.
