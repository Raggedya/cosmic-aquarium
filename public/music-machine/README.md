# AGGITS machine visual assets

Both production assets were generated with the built-in OpenAI image-generation tool on 6 September 2026, using the user-supplied approved Melbourne Music Machine image as the reference. The generated sources remain in the Codex generated-image workspace; the checked-in files are responsive WebP derivatives.

## `aggits-cabinet.webp`

Role: photographic 1024-pixel-wide cabinet skin behind the live HTML reels, meters, ticker, controls and Bandcamp transport.

Prompt summary: a straight-on, perfectly centred, hyperrealistic vertical vintage music-machine cabinet with dark walnut, aged brass, black chrome and warm amber tubes; blank arched marquee, title plate, twin meter apertures, three cream reel windows, ticker slot, control deck and speaker grille; no text, logos, gambling symbols, money or lever handle.

## `aggits-lever.webp`

Role: separate interactive side-lever skin. Live pointer and keyboard interaction is implemented in HTML/JavaScript; this file is only the material surface.

Prompt summary: an isolated heavy vintage lever with black Bakelite ball, aged brass/black-chrome arm and circular mechanical pivot, vertical resting orientation, realistic metal wear and warm amber highlights; no cabinet, text, symbols, hands, coins or casino imagery.

The reference image and generated raster surfaces are not used to encode band names, song names, results, or controls. Those remain live, accessible and data-driven.
