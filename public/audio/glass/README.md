# Cosmic Aquaria glass impacts

`glass-impact-mobile.mp3` and `glass-impact-go-mobile.mp3` are short mono composites built from the four CC0 recordings documented in `source/metadata.json`. They preserve the pressure, primary crack, granular crunch, and shard-settle layers in a single MP3 that Safari can start directly from the listener's first gesture.

Rebuild them with `python scripts/build-glass-impact-fallbacks.py`. The layered Web Audio treatment remains the primary path outside the Apple WebKit fallback.
